# ULC-LexDrive

"ULC LexDrive" is a student created platform designed to consolidate college previous year question paper PDFs in one place.
Many students find it difficult to locate old question papers because they are scattered across WhatsApp groups, different folders and personal devices.
ULC LexDrive aims to make access easier by organizing these PDFs in a simple and convenient manner.

The purpose of this platform is only to:
* Collect available college PYQ PDFs
* Organize them subject-wise and semester-wise
* Provide quick and easy access for students

It is only a repository of available college question paper PDFs intended to help students find them more easily.
